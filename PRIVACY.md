# Privacy policy

This policy covers the OrcaSlicer MCP skills plugin (`orcaslicer-mcp-skills`), published by the
OrcaSlicer project.

The plugin is a set of instructions for an AI agent: one skill and its reference files. It contains
no executable code, installs no MCP server and makes no network requests. It collects no personal
data, stores nothing, and sends nothing to the OrcaSlicer project or to anyone else.

When you use the skill, your agent talks to the OrcaSlicer MCP server running on your own computer,
which accepts connections from that computer only. Your prompts, files and the agent's replies are
handled by the agent you use, under its provider's privacy policy, such as Anthropic's for Claude or
OpenAI's for Codex.

Questions about this policy go to the project's
[GitHub issues](https://github.com/OrcaSlicer/orcaslicer-mcp-skills/issues).

Effective 29 October 2026.
